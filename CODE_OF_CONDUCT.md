# Código de conducta

## Nuestro compromiso

Nos comprometemos a que la participación en este proyecto sea una experiencia
libre de acoso para todas las personas, independientemente de su edad, cuerpo,
discapacidad, etnia, identidad y expresión de género, nivel de experiencia,
nacionalidad, apariencia, raza, religión u orientación sexual.

## Comportamiento esperado

- Usar lenguaje respetuoso e inclusivo.
- Aceptar críticas técnicas con apertura y dar retroalimentación constructiva.
- Priorizar la seguridad de los usuarios y de terceros.
- Respetar el alcance autorizado: este proyecto no debe usarse para atacar
  sistemas sin permiso.

## Comportamiento inaceptable

- Acoso, insultos, discriminación o amenazas.
- Publicar información privada de otras personas sin consentimiento.
- Compartir secretos, datos de clientes o vulnerabilidades explotables.
- Promover uso ofensivo no autorizado.

## Aplicación

Los mantenedores pueden editar, rechazar o eliminar contribuciones y comunicaciones
que violen este código, y pueden suspender la participación temporal o
permanentemente. Reportes: por un canal privado a los mantenedores del repositorio.

Este código está inspirado en el Contributor Covenant, versión 2.1.
